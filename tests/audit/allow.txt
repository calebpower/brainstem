# tests/audit/allow.txt — the external surface brainstem is allowed to have.
#
# One line per "unit symbol", read by tools/bsaudit.sh (tier 10b) against the
# objects the compiler emitted. Adding a line here is the only way to add a
# dependency, and it is a review event: every line is a thing this program
# reaches outside itself to do.
#
# ONE FILE FOR BOTH PLATFORMS. Rows naming a unit this build did not produce
# are vacuous rather than stale -- sys_freebsd is not built on Linux -- which
# is what lets the two platforms share a single statement of the surface.
#
# Symbol names are the ones the SOURCE uses. The audit undecorates what the
# toolchain emitted first, so __fprintf_chk matches fprintf and __error
# matches errno, and it ignores the pure memory and string helpers outright
# because whether those appear at all is the compiler's choice rather than
# the program's. See normalise() in the audit for both.
#
# Note what is NOT here, and could not be added without an argument: no
# malloc, no fopen, no getenv, no setlocale, and nothing whatever for frame,
# err, op_ctl, op_time, op_rand or det. Those six units reference nothing
# outside themselves, which is the strongest single thing this file says.

# ---- broker.c: the one unit that touches the wire ----
broker errno
broker fprintf
broker fputc
broker poll
broker read
broker stderr
broker write
